# Portfolio — Pierre Cancalon

> Un portfolio interactif à l’esthétique rétro-futuriste, pensé comme un dossier d’archives et consacré à mon parcours entre création numérique, administration système et cybersécurité.

## 🌐 Accès au site

**Site en ligne :** [https://pioupious.github.io/Portfolio/](#)

> Remplacez `#` par l’URL publique du portfolio une fois le site déployé.

## ✨ À propos

Ce portfolio présente le parcours de Pierre Cancalon, de ses expériences en 3D et en effets visuels à sa reconversion vers la cybersécurité. Il rassemble ses compétences, ses expériences professionnelles, ses formations et quelques projets dans une interface inspirée des archives de science-fiction.

### Ce que vous y trouverez

- **À propos** — présentation du parcours et de la reconversion.
- **Compétences** — systèmes, réseaux, cybersécurité, supervision et développement.
- **Expériences** — missions professionnelles présentées sous forme de fiches dépliables.
- **Formation** — cursus et apprentissages.
- **Projets** — réalisations personnelles et projets en cours.
- **Contact** — liens vers les réseaux et formulaire de contact.
- **Animation** — un rover qui accompagne le défilement de la page.

## 🧰 Technologies

- [React 19](https://react.dev/) — interface en composants.
- [Vite](https://vite.dev/) — serveur de développement et bundler.
- JavaScript, HTML et CSS.
- ESLint — vérification et qualité du code.

## 🚀 Lancer le projet en local

### Prérequis

- [Node.js](https://nodejs.org/) (version compatible avec Vite 8).
- npm.

### Installation

```bash
git clone <URL_DU_DEPOT>
cd <DOSSIER_DU_PROJET>
npm install
```

### Développement

```bash
npm run dev
```

Vite affiche dans le terminal l’adresse locale à ouvrir dans votre navigateur.

### Vérification et aperçu de production

```bash
npm run lint
npm run build
npm run preview
```

La commande `build` génère le site dans le dossier `dist/`. `preview` permet de vérifier localement cette version de production.

### Déploiement sur GitHub Pages

```bash
npm run deploy
```

Cette commande génère le site puis publie le contenu de `dist/` sur la branche `gh-pages`.
